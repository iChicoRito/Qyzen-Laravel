# Objective

## Resolve Assessment, Question Bank, and Learning Materials Issues

---

## Role

You are a software engineer and quality assurance specialist responsible for diagnosing functional defects, refining interface labels, preserving user-selected filters, and ensuring shared-file behavior across multiple sections and subjects.

---

## Description

Resolve multiple functional and usability issues affecting the educator’s Assessment, Question Bank, and Learning Materials pages. Investigate intermittent server errors, correct specified context-menu labels, and ensure that active filters remain applied after users perform actions such as creating, duplicating, or editing records. Clarify and implement the expected behavior for uploading a single question or learning-material file to multiple sections or subjects without creating duplicate file or question records. Additionally, repair the Learning Materials term filter so that it returns existing materials associated with the selected term.

---

## Primary Objective

Improve the reliability and usability of educator content-management workflows by fixing reported errors, preserving filter state, correcting interface labels, and preventing duplicate records during multi-section or multi-subject uploads.

---

## Secondary Objectives

* Resolve the intermittent unexpected-server-response error that occurs when creating or duplicating assessments.
* Update the Assessment context-menu labels to use shorter and correctly spelled terminology.
* Preserve active Assessment filters after create, edit, duplicate, or similar actions.
* Support selecting multiple sections or subjects when uploading Question Bank files, where applicable.
* Ensure that a single Question Bank upload shared across multiple sections or subjects does not create duplicate files or duplicate question records.
* Ensure that a single Learning Materials upload shared across multiple sections or subjects does not create duplicate file records.
* Fix the Learning Materials term filter so that it displays materials associated with an existing selected term.

---

## Success Criteria

* Creating or duplicating an assessment no longer intermittently displays “The server returned an unexpected response.”
* The context-menu label “Manage Exemptions” is changed to “Exemptions.”
* The context-menu label “Manage Speciall Access” is changed to “Special Access.”
* Active Assessment filters remain applied after users create, edit, duplicate, or perform other supported actions.
* The Question Bank upload workflow allows multiple section or subject selections when subject selection is required.
* Uploading one Question Bank file to multiple sections or subjects creates one shared source without duplicating the file or its questions.
* Uploading one Learning Materials file to multiple sections or subjects creates one shared source without duplicating the file.
* Selecting a valid term in the Learning Materials filter displays the corresponding existing materials instead of incorrectly showing “No materials.”

---

## Constraints

* Multi-section and multi-subject uploads must reuse the same underlying file and content rather than create duplicate records.
* Shared Question Bank uploads must not produce duplicate questions.
* Existing actions on the Assessment page must not clear the user’s active filter selections.

---

## Context & Dependencies

* The affected functionality is used by educators.
* The reported issues span the Assessment, Question Bank, and Learning Materials pages.
* The expected upload model is shared access: one uploaded file or question set should be associated with multiple selected sections or subjects.
* The implementation may depend on how files, questions, subjects, sections, terms, and their associations are currently represented in the application and database.

## Detailed Breakdown

### Assessment Creation and Duplication Error

The Assessment page intermittently displays “The server returned an unexpected response” when an educator creates or duplicates an assessment. The failure must be reproduced under both workflows and traced through the frontend request, backend processing, validation, persistence, and returned response. The underlying cause must be corrected rather than only suppressing the visible error.

### Context-Menu Terminology

The Assessment context menu must use concise and correctly spelled labels. Replace “Manage Exemptions” with “Exemptions” and replace “Manage Speciall Access” with “Special Access.” The changes must be applied consistently wherever those context-menu actions appear.

### Assessment Filter Retention

When an educator applies a filter and then performs an action such as creating, editing, or duplicating an assessment, the selected filter is currently removed. The page must retain the active filter values and continue displaying the filtered results after the action completes. Educators should not need to configure the same filter repeatedly while completing related tasks.

### Shared Question Bank Uploads

Determine whether a subject must be selected during Question Bank uploads. When categorization by subject or section is required, the upload interface must support selecting multiple destinations. A file uploaded once for several subjects or sections must remain a single shared upload, and the questions extracted or stored from that file must also remain a single shared question set rather than being duplicated for each association.

### Shared Learning Materials Uploads

A Learning Materials file assigned to multiple subjects or sections must be stored once and shared across all selected destinations. The system must create the required relationships without duplicating the uploaded file or maintaining separate copies for each subject or section.

### Learning Materials Term Filtering

The term filter on the Learning Materials page currently returns “No materials” even when materials exist for the selected term. The filtering query and its associated term relationships must be corrected so that existing materials are returned accurately. The empty-state message should appear only when the selected term genuinely has no associated materials.
